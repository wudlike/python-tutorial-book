## 4.1 条件语句——让程序做出选择

前面的章节中，程序总是按顺序一行行执行，没有任何"岔路"。条件语句的出现让程序拥有了**判断能力**——根据不同的情况走不同的分支。这是程序从"死板的执行器"升级为"灵活的决策者"的关键一步。

### 4.1.1 `if` 语句：最基础的条件判断

`if` 是条件语句的起点，它的执行逻辑很简单：**如果条件成立，就执行指定的代码块；否则直接跳过**。

```python
score = 85

if score >= 60:
    print("恭喜，你及格了！")
print("程序结束")
```

**执行流程：**

```text
score >= 60 ？
   ├── True  → 执行 print("恭喜，你及格了！")
   └── False → 跳过 if 内的代码
          ↓
      print("程序结束")  ← 无论条件是否成立，这行都会执行
```

**语法要点：**

1. `if` 后接一个布尔表达式（结果为 `True` 或 `False`）
2. 条件后必须加冒号 `:`
3. 属于 `if` 的代码块必须**缩进 4 个空格**
4. 缩进结束即表示代码块结束

```python
age = 16

if age >= 18:
    print("可以考驾照")
    print("可以投票")
# 这两行没缩进，不属于 if，始终会执行
print("年龄判断完毕")
```

---

\begin{definitionbox}
**什么是"代码块"？**

代码块是一组以相同缩进量写在一起的语句，它们构成了一个逻辑整体。在 Python 中，缩进不仅是美观问题——它直接决定了代码块的范围。缩进错误会导致程序逻辑完全改变或直接报错，所以务必保持缩进一致（统一用 4 个空格）。
\end{definitionbox}

---

### 4.1.2 `if-else`：二选一的分岔路

`if` 只能处理"条件成立时做什么"，`else` 则补上了"条件不成立时做什么"——形成完整的二选一结构。

```python
score = 55

if score >= 60:
    print("及格")
else:
    print("不及格")
# 输出：不及格
```

`if` 和 `else` 之间**有且仅有一条**分支会执行，不可能两条都执行，也不可能一条都不执行。

### 4.1.3 `if-elif-else`：多分支决策

当需要判断的情况超过两种时，用 `elif`（else if 的缩写）扩展分支。从上到下依次检查，**命中第一个为 True 的条件后就不再往下判断**。

```python
score = 82

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "不及格"

print(f"你的等级是：{grade}")  # 输出：你的等级是：B
```

**执行顺序分析：**

```text
score = 82
  ↓
score >= 90 ？→ False，继续往下
score >= 80 ？→ True！grade = "B"，不再往下判断
```

---

\begin{warningbox}
**`elif` 的顺序很重要！**

如果条件排列不当，后面的分支可能永远执行不到：

```python
# 错误顺序
score = 95
if score >= 60:
    grade = "D"        # 先匹配了这里！
elif score >= 90:
    grade = "A"        # 永远不会执行到这
```

正确的做法是**从严格到宽松**排列条件：`>= 90` → `>= 80` → `>= 70` → ... → `else`。
\end{warningbox}

---

### 4.1.4 条件语句的嵌套

一个条件语句内部可以再写条件语句，形成嵌套判断。但建议**嵌套不超过两层**，否则可读性急剧下降。

```python
age = 22
has_id = True

if age >= 18:
    if has_id:
        print("可以进入")
    else:
        print("需要出示身份证")
else:
    print("未成年，禁止进入")
```

### 4.1.5 条件表达式（三元运算符）

当 `if-else` 结构简单到"根据条件给变量赋不同的值"时，可以用一行写完：

```python
# 常规写法
if score >= 60:
    status = "及格"
else:
    status = "不及格"

# 三元表达式（一行写法）
status = "及格" if score >= 60 else "不及格"
```

语法：`值1 if 条件 else 值2`——条件为 True 取值 1，否则取值 2。

### 4.1.6 实战练习

1. 用户输入一个年份，编写程序判断该年是否为闰年。闰年规则：能被 4 整除但不能被 100 整除，**或者**能被 400 整除。

2. 编写简单的 BMI 计算器：用户输入身高（米）和体重（千克），计算 BMI = 体重 / 身高²，根据以下标准输出体型评价：

   | BMI 范围 | 评价 |
   |:---------|:-----|
   | < 18.5 | 偏瘦 |
   | 18.5 ~ 23.9 | 正常 |
   | 24.0 ~ 27.9 | 偏胖 |
   | ≥ 28.0 | 肥胖 |

3. 模拟外卖满减：用户输入订单金额，按以下规则计算实付金额并输出：
   - 满 100 减 20
   - 满 50 减 8
   - 满 30 减 3
   - 不足 30 不减

   要求：使用 `if-elif-else` 结构，且计算最大优惠（如订单金额 120 元，应该减 20，而不是减 8）。
