# 第16章：综合项目——个人记账系统

在日常生活中，我们每天都会产生各种收入和支出——工资入账、餐饮消费、交通费用、房租水电……如果能用一个自己写的程序来记录和分析这些账目，不仅能锻炼编程能力，还能实实在在地帮助自己管理财务。本章将从零开始，带你构建一个完整的个人记账系统。
