## 6.1 函数的定义与调用——代码"积木块"

如果把写程序比作搭乐高积木，函数就是每一块标准化零件。你不需要在每个地方都从零开始拼——把最常用的逻辑封装成一个函数，以后需要时直接"拿过来用"即可。函数让代码从"一长串面条"变成"一段段可复用的模块"。

### 6.1.1 为什么要用函数？

在写了几十行代码之后，你可能会注意到一些模式——某几行代码反复出现，只是变量名不同。比如在多个地方都要计算"两个数的平均值"，你可能会拷贝粘贴同样的代码。这带来了三个问题：

1. **重复代码**：同样的逻辑写了三遍，修改时要改三处，漏一处就出 bug
2. **可读性差**：一屏代码从头铺到尾，没有结构层次，别人（包括三个月后的自己）很难理清逻辑
3. **难以测试**：混在一起的代码无法单独验证某段逻辑是否正确

函数的出现正是为了解决这三个问题。**函数就是将一段具有独立功能的代码封装起来，给它起个名字，在需要的时候通过名字调用它。**

### 6.1.2 定义函数

Python 中用 `def` 关键字定义函数，格式为：

```python
def 函数名(参数列表):
    """文档字符串（可选）"""
    函数体
    return 返回值（可选）
```

一个最简单的例子：

```python
def greet():
    """打印一句问候语"""
    print("Hello, Python!")

greet()               # 调用函数，输出：Hello, Python!
greet()               # 可以反复调用
```

逐行拆解这个定义：
- `def` 是定义函数的关键词，告诉 Python"接下来我要定义一个函数了"
- `greet` 是函数名，命名规则和变量名一致——蛇形命名，见名知意
- 括号 `()` 里放参数列表（当前为空，表示不需要外部传入数据）
- 冒号 `:` 开启函数体，下面的代码必须缩进 4 个空格
- `"""..."""` 是三引号文档字符串，描述函数功能，后面可通过 `help(greet)` 查看
- 函数体是需要执行的代码
- `greet()` 是**调用**函数——定义只是"登记在册"，调用才真正执行

**有参数、有返回值的函数：**

```python
def add(a, b):
    """返回两个数的和"""
    return a + b

result = add(3, 5)
print(result)          # 8
print(add(10, 20))     # 30——直接打印返回值
```

---

\begin{definitionbox}
**函数的三个核心元素**

每个函数由三部分组成，缺一不可：
- **输入（参数）**：函数调用时从外部接收的数据，`def add(a, b)` 中的 `a` 和 `b`
- **处理（函数体）**：函数内部执行的逻辑，`a + b`
- **输出（返回值）**：函数处理完交给外部的数据，`return a + b`

没有 `return` 语句的函数默认返回 `None`。上面 `greet()` 函数就是这种情况——它只执行了 `print()`，但并没有 `return` 任何值。这一点在后面的"返回值和作用域"一节中会详细展开。
\end{definitionbox}

---

### 6.1.3 函数的"先定义，后调用"原则

Python 是解释型语言，代码从上到下逐行执行。调用一个函数之前，必须确保它已经被定义过：

```python
say_hello()                   # NameError！函数还没定义

def say_hello():
    print("Hello!")
```

正确的顺序是定义在前，调用在后。这个规则看似简单，但在大型项目中有时会被忽略——比如你从别的文件导入函数时，需要确保导入语句在调用之前。

### 6.1.4 文档字符串——给函数写"说明书"

三个双引号包裹的文档字符串（docstring）不是必须的，但强烈建议每个函数都写。它不仅是给别人看的注释，还能被 Python 的内置 `help()` 函数识别和展示：

```python
def calculate_bmi(weight, height):
    """计算 BMI 指数。

    参数：
        weight: 体重（千克）
        height: 身高（米）

    返回值：
        BMI 值（浮点数）
    """
    return weight / (height ** 2)

help(calculate_bmi)
```

养成写 docstring 的习惯，会让自己在三个月后回头看代码时感激现在的自己。

### 6.1.5 实战练习

1. 定义一个名为 `is_even` 的函数，接收一个整数参数，返回该数是否为偶数（`True` 或 `False`）。调用该函数分别测试 7 和 12。

2. 定义一个名为 `triangle_area` 的函数，接收底边长度和高两个参数，返回三角形面积（面积 = 底 × 高 ÷ 2）。用 `4` 和 `5` 作为参数调用并输出结果。

3. 定义一个名为 `print_multiplication_table` 的函数，接收一个整数参数 `n`，打印 `n` 的乘法口诀（从 `1×n` 到 `9×n`）。例如 `print_multiplication_table(7)` 应输出：

```text
1 × 7 = 7
2 × 7 = 14
...
9 × 7 = 63
```
