## A.1 VS Code 快捷键

VS Code 是当前最流行的 Python 编辑器，轻量且功能强大。掌握以下快捷键，编码效率翻倍。

### A.1.1 编辑操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + /` | 注释/取消注释 | 自动识别语言，添加 `#` 注释 |
| `Ctrl + [` / `Ctrl + ]` | 减少/增加缩进 | 调整代码块缩进层级 |
| `Alt + ↑/↓` | 上/下移动当前行 | 整行移动，比剪切粘贴快得多 |
| `Shift + Alt + ↑/↓` | 向上/下复制当前行 | 快速复制代码行 |
| `Ctrl + Shift + K` | 删除当前行 | 比选中再删除快 |
| `Ctrl + Enter` | 下方插入空行 | 光标不动，下方新增一行 |
| `Ctrl + Shift + Enter` | 上方插入空行 | 光标不动，上方新增一行 |
| `Ctrl + D` | 选中下一个相同词 | 批量修改变量名 |
| `Ctrl + Shift + L` | 选中所有相同词 | 一次性选中所有匹配项 |
| `Ctrl + F2` | 重命名符号 | 智能重命名变量/函数，更新所有引用 |
| `Alt + Click` | 多光标编辑 | 在多个位置同时输入 |
| `Ctrl + Alt + ↑/↓` | 向上/下添加光标 | 列编辑模式 |

### A.1.2 导航与搜索

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + P` | 快速打开文件 | 输入文件名关键字即可定位 |
| `Ctrl + Shift + P` | 命令面板 | 所有 VS Code 功能的入口 |
| `Ctrl + G` | 跳转到指定行 | 输入行号直接跳转 |
| `Ctrl + Shift + O` | 跳转到符号 | 在当前文件中搜索函数/类名 |
| `Ctrl + T` | 全局符号搜索 | 跨文件搜索函数/类 |
| `Ctrl + F` | 当前文件搜索 | 在当前文件内查找文本 |
| `Ctrl + H` | 查找并替换 | 支持正则表达式 |
| `Ctrl + Shift + F` | 全局搜索 | 在整个项目/工作区中搜索 |
| `F12` | 跳转到定义 | 查看函数/类在哪里定义的 |
| `Alt + F12` | 查看定义（Peek） | 弹窗预览定义，不跳转 |
| `Shift + F12` | 查找所有引用 | 查看哪些地方使用了该符号 |
| `Ctrl + -` | 返回上一个位置 | 跳转后回到原来的地方 |
| `Ctrl + Tab` | 切换最近文件 | 在打开的文件之间快速切换 |

### A.1.3 运行与调试

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `F5` | 开始调试 | 运行当前 Python 文件并附加调试器 |
| `Shift + F5` | 停止调试 | 终止正在运行的调试会话 |
| `F9` | 切换断点 | 在当前行添加/移除断点 |
| `F10` | 单步跳过 | 执行当前行，不进入函数内部 |
| `F11` | 单步进入 | 进入函数内部调试 |
| `Shift + F11` | 单步跳出 | 执行完当前函数并跳出 |
| `Ctrl + F5` | 运行（不调试） | 直接运行当前文件 |
| `Ctrl + `` ` | 打开终端 | 在 VS Code 内打开集成终端 |

### A.1.4 代码格式化

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Shift + Alt + F` | 格式化文档 | 自动对齐、调整缩进 |
| `Ctrl + K Ctrl + F` | 格式化选中区域 | 只格式化选中的代码 |
| `Ctrl + .` | 快速修复 | 自动导入缺失的模块、修复错误 |
| `Ctrl + Space` | 触发建议 | 代码补全提示 |
| `Ctrl + Shift + Space` | 参数提示 | 查看函数参数列表 |

### A.1.5 窗口管理

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + B` | 切换侧边栏 | 显示/隐藏文件资源管理器 |
| `Ctrl + J` | 切换面板 | 显示/隐藏终端面板 |
| `Ctrl + \` | 拆分编辑器 | 左右分屏，对照编辑 |
| `Ctrl + 1/2/3` | 聚焦编辑器组 | 在分屏之间切换 |
| `Ctrl + W` | 关闭当前标签 | 关闭当前文件 |

| 快捷键 | 功能 |

## A.5 通用效率技巧

### A.5.1 代码片段（Snippets）

大多数编辑器都支持自定义代码片段——输入简短的触发词，自动展开为完整的代码模板。

**VS Code 中配置 Python Snippets**：`文件 → 首选项 → 配置用户代码片段 → python.json`

```json
{
    "if __name__": {
        "prefix": "ifmain",
        "body": "if __name__ == \"__main__\":\n    ${1:pass}",
        "description": "主入口"
    },
    "class template": {
        "prefix": "cls",
        "body": "class ${1:ClassName}:\n    def __init__(self, ${2:args}):\n        ${3:pass}",
        "description": "类模板"
    }
}
```

输入 `ifmain` 再按 `Tab`，自动展开为 `if __name__ == "__main__":`。

### A.5.2 多光标编辑场景

| 场景 | 操作 |
|------|------|
| 批量添加引号 | 选中多行末尾 → `Shift + Alt + I`（多光标）→ 输入引号 |
| 对齐赋值 | 在所有 `=` 前加空格 → `Ctrl + D` 逐个选中 `=` |
| 批量注释 | `Ctrl + /`（比手动逐行加 `#` 快 N 倍） |

| isort | 自动排序 import 语句 |
