## 5.4 集合——"去重 + 集合运算"的数学工具

集合是四种数据结构中最"专精"的一个——它不擅长存放有序数据，也不擅长用名字查找，但它在**去重**和**集合运算**（交集、并集、差集）这两件事上做到了极致。如果你的需求恰好落在这两个领域，集合能让你用一行代码完成其他数据结构需要好几行才能实现的功能。

### 5.4.1 什么是集合？

集合是一组**无序的、不重复的**元素。创建集合有两种方式：花括号（注意和字典的区别——没有冒号就是集合）或 `set()` 函数。

```python
fruits = {"苹果", "香蕉", "橘子"}
print(fruits)           # 输出顺序可能每次不同（无序）

numbers = {1, 2, 3, 3, 2, 1}
print(numbers)          # {1, 2, 3}——重复元素自动消失
```

注意区分：
- `{}` 是空字典，不是空集合
- 创建空集合必须用 `set()`：`empty = set()`

---

\begin{definitionbox}
**集合的核心特性：元素唯一且无序**

这两个特性决定了集合的天然适用场景：

- **唯一性**：任何元素在集合中最多出现一次。这意味着你可以把列表转成集合来实现去重——`set([1, 1, 2, 2, 3])` 的结果是 `{1, 2, 3}`。与手动遍历列表去重相比，集合去重不仅代码更简洁，而且在大数据量下速度快得多。
- **无序性**：集合没有索引，不能通过位置访问元素。想取"第 3 个元素"？集合做不到。但你可以遍历集合，也可以判断某个元素是否存在于集合中。
\end{definitionbox}

---

### 5.4.2 集合的基本操作

#### 添加与删除

```python
nums = {1, 2, 3}

nums.add(4)              # 添加元素（若已存在则无变化）
print(nums)              # {1, 2, 3, 4}

nums.remove(2)           # 删除元素（元素不存在则报错 KeyError）
print(nums)              # {1, 3, 4}

nums.discard(5)          # 安全删除——元素不存在也不会报错
print(nums)              # {1, 3, 4}

item = nums.pop()        # 随机删除并返回一个元素（因为无序，无法预期删哪个）
print(item, nums)
```

---

\begin{tipbox}
**`remove` vs `discard`：一个安全的习惯**

```python
s = {1, 2, 3}
s.discard(99)   # 没问题，静默跳过
s.remove(99)    # KeyError！
```

如果你不确定元素是否在集合中，优先用 `discard`。只有在你**确定**元素必须存在、不存在就是逻辑错误的情况下，才用 `remove` 让它帮你发现 bug。
\end{tipbox}

### 5.4.3 集合运算——交集、并集、差集

这是集合最强大的能力。如果你在数学课上学过集合的韦恩图（Venn Diagram），下面这些操作对你来说就是老相识了。

```python
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}

print(a & b)      # 交集（Intersection）：{4, 5}——两边都有的元素
print(a | b)      # 并集（Union）：{1, 2, 3, 4, 5, 6, 7, 8}——两边任意有的元素
print(a - b)      # 差集（Difference）：{1, 2, 3}——在 a 中但不在 b 中的元素
print(b - a)      # 差集：{6, 7, 8}——在 b 中但不在 a 中的元素
print(a ^ b)      # 对称差集（Symmetric Difference）：{1, 2, 3, 6, 7, 8}——仅在单边出现的元素
```

每种运算也提供等价的**方法形式**（对熟悉面向对象风格的读者可能更直观）：
- `a & b` 等价于 `a.intersection(b)`
- `a | b` 等价于 `a.union(b)`
- `a - b` 等价于 `a.difference(b)`
- `a ^ b` 等价于 `a.symmetric_difference(b)`

**实际应用举例：** 假设你管理一个学习平台，有两个课程的学生名单：

```python
python_students = {"小明", "小红", "小刚", "小李"}
java_students = {"小刚", "小李", "小王", "小赵"}

# 选了 Python 或 Java 的总人数（去重）
all_students = python_students | java_students
print(f"总选课人数：{len(all_students)}")              # 6

# 同时选了两门课的学生
both = python_students & java_students
print(f"两门都选的：{both}")                          # {'小刚', '小李'}

# 只选了 Python 的学生
only_python = python_students - java_students
print(f"只选 Python 的：{only_python}")               # {'小明', '小红'}
```

### 5.4.4 集合推导式

```python
squares = {x ** 2 for x in range(1, 6)}
print(squares)    # {1, 4, 9, 16, 25}

nums = {1, 2, 3, 4, 5, 6}
evens = {x for x in nums if x % 2 == 0}
print(evens)      # {2, 4, 6}
```

### 5.4.5 四种数据结构对比总览

学完了四种数据结构，来一张全家福对比：

| 结构 | 写法 | 有序？ | 可变？ | 允许重复？ | 典型用途 |
|:----:|:----:|:----:|:----:|:--------:|:-----|
| 列表 | `[1, 2, 3]` | ✅ 是 | ✅ 是 | ✅ 是 | 购物车、成绩单、待办事项 |
| 元组 | `(1, 2, 3)` | ✅ 是 | ❌ 否 | ✅ 是 | 坐标、RGB 颜色、函数多返回值 |
| 字典 | `{"a": 1}` | ✅ 是（3.7+） | ✅ 是 | ❌ 键不可重复 | 配置、缓存、JSON 数据、统计计数 |
| 集合 | `{1, 2, 3}` | ❌ 否 | ✅ 是 | ❌ 否 | 去重、交集/并集、成员快速判断 |

选择数据结构的思路可以概括为三个问题：
1. 数据需要按**名字**访问吗？→ 用字典
2. 数据需要**去重**或做**集合运算**吗？→ 用集合
3. 数据**不可修改**吗？→ 用元组；否则用列表

1. 给定两个列表 `list1 = [1, 2, 3, 4, 5]` 和 `list2 = [4, 5, 6, 7, 8]`，使用集合运算实现以下功能：
   - 找出两个列表的共同元素
   - 找出只在 `list1` 中出现的元素
   - 生成两个列表的合并去重结果

2. 一个班级有 30 人，期中考试有 28 人参加，期末考试有 27 人参加，两次都参加的有 26 人。分别计算：没参加期中考试的人数、没参加期末考试的人数，以及两次都没参加的人数。（提示：用集合建模——全班是全集，期中参加的是子集 A，期末参加的是子集 B）

3. 编写程序，用户输入一串字母（如 `"abracadabra"`），统计其中出现了哪些不重复的字母，并按字母顺序输出。例如输入 `"abracadabra"` 应输出 `{'a', 'b', 'c', 'd', 'r'}`。
