## 5.3 字典——"键值对"的快速查找引擎

如果列表像一排编了号的储物柜，你找东西需要记住"它在第几号柜子"；字典则像一本电话簿——你想找"小明的电话号码"，不需要翻遍每一页，而是直接翻到"小明"这一条目。字典用"名字"而非"位置"来查找数据，这种查找方式在处理复杂信息时自然得多。

### 5.3.1 什么是字典？

字典由一对对**键（key）和值（value）**组成。键是"名字"，值是"内容"；通过键可以快速查到对应的值。字典用**花括号 `{}`** 创建，键和值之间用冒号 `:` 连接，每对之间用逗号分隔。

```python
student = {
    "name": "小明",
    "age": 20,
    "score": 88,
    "city": "北京"
}

print(student["name"])     # 小明——通过键 "name" 查值
print(student["age"])      # 20
print(student["score"])    # 88
```

字典和列表的区别贯穿于整个数据访问模式：

| 维度 | 列表 | 字典 |
|:-----|:-----|:-----|
| 访问方式 | `lst[0]`（按位置编号） | `d["key"]`（按键名） |
| 顺序 | 有固定顺序（Python 3.7+ 保证插入顺序） | 有插入顺序，但不按位置查 |
| 查找速度 | 按索引查 O(1)，按值查 O(n) | 按键查 O(1)，极快 |
| 键的要求 | 无 | 键必须是不可变类型（字符串、数字、元组） |
| 典型场景 | 批量处理、有序数据 | 配置信息、快速查找、统计计数 |

---

\begin{definitionbox}
**理解字典的"哈希表"本质（科普，无需死记）**

字典之所以能"一瞬间"根据键找到值，是因为它在幕后使用了**哈希表**（Hash Table）——一种精心设计的数据结构。你不用理解哈希表的具体实现，但可以记住这个直觉：字典就像图书馆的管理系统，每本书（值）都配了一个索书号（键），当你需要某本书时，系统通过索书号瞬间定位到书架位置，而不需要一本一本翻找。这也是为什么字典的键必须是不可变的——索书号不能变来变去，否则就找不到书了。
\end{definitionbox}

### 5.3.2 字典的基本操作

#### 访问与修改

```python
person = {"name": "小红", "age": 18}

print(person["name"])           # 小红——直接通过键访问
print(person.get("gender"))     # None——键不存在时返回 None，不报错
print(person.get("gender", "未知"))  # 未知——可指定默认值

person["age"] = 19              # 修改已有的值
person["city"] = "上海"          # 添加新的键值对（键不存在则自动新增）
print(person)                   # {'name': '小红', 'age': 19, 'city': '上海'}
```

**`get()` vs `[]`：** 用方括号访问不存在的键会直接抛出 `KeyError` 使程序崩溃；而 `get()` 会优雅地返回 `None`（或你指定的默认值）。在处理来源不确定的数据（比如用户输入、API 返回、配置文件）时，`get()` 是更安全的访问方式。这也是防御性编程的一个小习惯——永远假设数据可能不完整。

#### 删除与清空

```python
person = {"name": "小红", "age": 18, "city": "北京"}

age = person.pop("age")          # 删除 "age" 并返回它的值
print(age)                       # 18
print(person)                    # {'name': '小红', 'city': '北京'}

removed = person.pop("gender", "不存在")  # 键不存在时不报错，返回默认值
print(removed)                   # 不存在

person.clear()                   # 清空字典
print(person)                    # {}
```

### 5.3.3 遍历字典

字典有三种遍历维度：键、值、键值对。选择哪一种取决于你当前需要什么信息。

```python
scores = {"语文": 88, "数学": 95, "英语": 73}

# 遍历键
for subject in scores:
    print(subject)                     # 语文 数学 英语

for subject in scores.keys():          # 与上面等价，更显式
    print(subject)

# 遍历值
for score in scores.values():
    print(score)                       # 88 95 73

# 遍历键值对——最常用
for subject, score in scores.items():
    print(f"{subject}: {score}分")
# 语文: 88分
# 数学: 95分
# 英语: 73分
```

在 95% 的场景中，你需要的都是 `items()`——同时拿到键和值。另外两种遍历方式只在特殊情况下用到，比如你只想检查字典中有哪些键（`keys()`）或想对所有值做统计计算（`values()`）。

### 5.3.4 字典推导式

和列表推导式类似，字典也有推导式语法：

```python
squares = {x: x ** 2 for x in range(1, 6)}
print(squares)    # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

words = ["apple", "banana", "orange"]
word_len = {w: len(w) for w in words}
print(word_len)   # {'apple': 5, 'banana': 6, 'orange': 6}
```

### 5.3.5 字典的嵌套——描述复杂信息

现实世界的信息往往是嵌套结构的——一个学生有多门课程成绩，一个公司有多个部门，一个订单包含多种商品。字典嵌套正是为这种场景而生。

```python
students = {
    "小明": {"语文": 88, "数学": 95, "英语": 73},
    "小红": {"语文": 92, "数学": 87, "英语": 96},
    "小刚": {"语文": 76, "数学": 82, "英语": 69},
}

print(students["小明"]["数学"])    # 95（两层访问）

# 计算每个学生的总分
for name, scores in students.items():
    total = sum(scores.values())
    print(f"{name} 总分：{total}")
# 小明 总分：256
# 小红 总分：275
# 小刚 总分：227
```

嵌套字典是 JSON 数据格式的 Python 映射，也是你未来处理 API 接口、数据库查询、配置文件时会反复遇到的结构。掌握 `students["小明"]["数学"]` 这种"按路径逐层访问"的思维，能帮助你在面对复杂数据时保持清晰的逻辑。
