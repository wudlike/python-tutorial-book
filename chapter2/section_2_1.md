## 2.1 第一个Python程序：Hello World

编程界有一条不成文的传统：学习任何一门新语言，第一个程序永远是让屏幕上出现 **"Hello, World!"**。这个仪式看似简单，实则承载了深层含义——它验证了你的开发环境已经就绪，标志着你和这门语言完成了第一次对话。

### 准备工作

在开始之前，请确认你的环境已配置正确。打开终端（Windows 中 `Win + R` 输入 `cmd`，macOS / Ubuntu 则直接打开"终端"），执行：

```bash
python --version
```

若输出 `Python 3.x.x`，说明环境已就绪。若提示找不到命令，请回溯第 1 章的安装步骤。

### 三种运行方式

Python 提供了多种运行代码的途径，从最直接的即时执行到正式的工程化开发，各有适用场景。

#### 方式一：命令行单行执行（最快验证）

无需创建文件，直接在终端中执行：

```bash
python -c "print('Hello, World!')"
```

`-c` 参数表示"把后面引号内的内容当作 Python 代码执行"。此方式适合临时验证某个语句是否可行，但不适合写多行逻辑。

#### 方式二：交互式环境（探索式编程）

在终端输入 `python`（或 `ipython`，如果已安装 Anaconda），进入交互模式：

```python
>>> print('Hello, World!')
Hello, World!
>>> 1 + 2
3
>>> name = 'Python'
>>> print(f'Hello, {name}!')
Hello, Python!
```

在 `>>>` 提示符后，每输入一行代码，Python 就会立刻执行并显示结果。这种"输入→即得反馈"的模式特别适合初学者快速验证语法、测试想法。输入 `exit()` 即可退出。

\begin{tipbox}

**交互式环境的两种选择**

- **Python 原生交互环境**：输入 `python` 进入，功能基础但无需额外安装
- **IPython**（Anaconda 自带）：输入 `ipython` 进入，提供语法高亮、Tab 补全、魔术命令（如 `%time` 测速），体验更佳

\end{tipbox}

#### 方式三：`.py` 脚本文件（推荐，正式开发方式）

这是实际工程中最常用的方式——将代码写入 `.py` 文件，然后一次性执行：

**第一步：创建文件**

用任意文本编辑器新建文件，命名为 `hello.py`。注意，扩展名必须是 `.py`，而不是 `.py.txt`（Windows 默认隐藏扩展名时容易出错，建议在文件资源管理器中开启"显示文件扩展名"）。

**第二步：写入代码**

```python
print("Hello, World!")
```

**第三步：运行**

在文件所在目录打开终端，执行：

```bash
# Windows
python hello.py

# macOS / Ubuntu
python3 hello.py
```

输出结果：

```
Hello, World!
```

\begin{tipbox}

**Windows 快捷技巧**

在 `hello.py` 所在文件夹中，按住 `Shift` + 右键 → 选择"在此处打开 PowerShell"，即可直接在文件目录下打开终端，省去手动 `cd` 切换路径的麻烦。

\end{tipbox}

### 代码解析

这一行代码虽然只有 25 个字符，但背后蕴含了 Python 执行流程的核心机制：

```python
print("Hello, World!")
```

| 组成部分 | 说明 |
|:---------|:-----|
| `print()` | Python 的**内置函数**，负责将内容输出到控制台。所谓"内置"，即无需 import 任何模块就能直接使用 |
| `"Hello, World!"` | 一个**字符串**（String），被双引号包裹的文本。字符串是 Python 最基础的数据类型之一 |
| `print("...")` | 语法结构为"函数名 + 括号 + 参数"。Python 解释器读取到这一行后，调用 `print()` 函数，将字符串发送到标准输出（屏幕） |

\begin{definitionbox}

**为什么输出不包含引号？**

引号（`'` 或 `"`）是代码中标记"这是一个字符串"的边界符号，Python 用它来区分字符串和代码指令。当 `print()` 将内容输出到屏幕时，只会输出字符串本身的内容，不会输出引号——因为此时已经没有"代码"和"数据"的区分了。

\end{definitionbox}

### 常见问题

| 问题 | 原因 | 解决 |
|:-----|:-----|:-----|
| `'python' 不是内部或外部命令` | Python 未添加到系统 PATH | 重新安装并勾选"Add Python to PATH"，或手动配置环境变量 |
| `SyntaxError: invalid syntax` | 语法错误（如引号不匹配、中英文符号混用） | 检查是否使用了中文引号（`""`），应使用英文引号（`""`） |
| `NameError: name 'xxx' is not defined` | 引用了未定义的变量或函数名 | 检查拼写，确保函数名正确（如 `print` 不是 `Print`，Python 区分大小写） |
