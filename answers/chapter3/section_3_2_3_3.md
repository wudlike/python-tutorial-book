## 3.2 变量与数据类型

### 练习1：自我介绍

**题目：** 定义变量存储你的"姓名、年龄、身高、是否喜欢 Python"，并打印出一句自我介绍。

**答案：**

```python
# 定义变量
name = "张三"
age = 20
height = 1.75
like_python = True

# 打印自我介绍
print(f"我叫{name}，今年{age}岁，身高{height}米，喜欢Python：{like_python}")
```

**输出：**

```
我叫张三，今年20岁，身高1.75米，喜欢Python：True
```

**解析：**
- 姓名和身高使用不同数据类型：`str` 和 `float`
- 年龄用 `int`，参与 f-string 拼接时无需手动转换
- `like_python` 用 `bool` 类型，`True` 首字母必须大写

### 练习2：成绩计算

**题目：** 定义一个列表存储 3 门课程的成绩（如 `[88, 95, 79]`），计算并打印"总成绩"和"平均成绩"（平均成绩保留 1 位小数）。

**答案：**

```python
# 定义成绩列表
score_list = [88, 95, 79]

# 计算总成绩
total = score_list[0] + score_list[1] + score_list[2]

# 计算平均成绩
average = total / 3

# 输出结果（保留1位小数）
print(f"总成绩：{total}，平均成绩：{round(average, 1)}")
```

**输出：**

```
总成绩：262，平均成绩：87.3
```

**解析：**
- 列表索引从 0 开始：`score_list[0]` 取第 1 个值（88）
- `round(average, 1)` 保留 1 位小数
- 也可以使用 `sum(score_list)` 来计算总和，更简洁：`total = sum(score_list)`

## 3.3 基本输入输出

### 练习1：圆的周长和面积

**题目：** 编写程序，提示用户输入圆的半径，计算并输出圆的周长和面积（保留 2 位小数）。圆周率使用 `3.14159`。

**答案：**

```python
# 定义圆周率
PI = 3.14159

# 接收用户输入的半径
radius = float(input("请输入圆的半径："))

# 计算周长和面积
circumference = 2 * PI * radius
area = PI * radius ** 2

# 输出结果（保留2位小数）
print(f"圆的周长：{circumference:.2f}")
print(f"圆的面积：{area:.2f}")
```

**输出示例（输入 5）：**

```
请输入圆的半径：5
圆的周长：31.42
圆的面积：78.54
```

**解析：**
- `input()` 返回字符串，用 `float()` 转换为小数
- `:.2f` 格式化保留 2 位小数
- `radius ** 2` 表示半径的平方

### 练习2：成绩单

**题目：** 编写程序，提示用户输入姓名和三门课程的成绩（整数），计算总分和平均分（保留 1 位小数），按指定格式输出成绩单。

**答案：**

```python
# 接收输入
name = input("请输入姓名：")
chinese = int(input("请输入语文成绩："))
math = int(input("请输入数学成绩："))
english = int(input("请输入英语成绩："))

# 计算
total = chinese + math + english
average = total / 3

# 输出成绩单
print("========成绩单========")
print(f"姓名：{name}")
print(f"语文：{chinese}  数学：{math}  英语：{english}")
print(f"总分：{total}")
print(f"平均分：{average:.1f}")
print("=====================")
```

**输出示例：**

```
请输入姓名：张三
请输入语文成绩：85
请输入数学成绩：92
请输入英语成绩：78
========成绩单========
姓名：张三
语文：85  数学：92  英语：78
总分：255
平均分：85.0
=====================
```

**解析：**
- `input()` 配合 `int()` 直接转为整数
- `:.1f` 使平均分保留 1 位小数
- 分隔线用 `=` 拼出，使输出整齐

### 练习3：收银台

**题目：** 编写一个简单的"收银台"程序：用户输入商品名称、单价和购买数量，程序计算总价并输出一张格式整齐的小票。要求金额保留 2 位小数，并使用对齐格式。

**答案：**

```python
# 接收商品信息
name = input("请输入商品名称：")
price = float(input("请输入单价："))
quantity = int(input("请输入购买数量："))

# 计算总价
total = price * quantity

# 输出小票
print("=" * 30)
print("欢迎光临".center(26))
print("=" * 30)
print(f"{'商品名称':<10}{'单价':>8}{'数量':>6}{'金额':>8}")
print("-" * 30)
print(f"{name:<10}{price:>8.2f}{quantity:>6}{total:>8.2f}")
print("-" * 30)
print(f"{'总价：':>20}{total:>8.2f}")
print("=" * 30)
```

**输出示例：**

```
请输入商品名称：苹果
请输入单价：5.5
请输入购买数量：3
==============================
           欢迎光临
==============================
商品名称        单价    数量      金额
------------------------------
苹果             5.50     3   16.50
------------------------------
                总价：   16.50
==============================
```

**解析：**
- `:<10` 左对齐，宽度 10；`:>8` 右对齐，宽度 8
- `:.2f` 金额保留 2 位小数
- `.center(26)` 字符串居中，宽度 26
- `"-" * 30` 生成 30 个短横线作为分隔符
