## 3.4 基本运算符

### 练习1：秒数拆分

**题目：** 将 3726 秒拆分为"小时:分钟:秒"格式。

**答案：**

```python
seconds = 3726

hours = seconds // 3600              # 3726 ÷ 3600 = 1（小时）
remaining = seconds % 3600           # 剩余 126 秒
minutes = remaining // 60            # 126 ÷ 60 = 2（分钟）
secs = remaining % 60                # 126 ÷ 60 的余数 = 6（秒）

print(f"{hours}:{minutes}:{secs}")   # 输出：1:2:6
```

**解析：**
- `//` 整除取商，`%` 取余数
- 先除以 3600（1小时=3600秒）得小时数
- 余数再除以 60 得分钟数，最后的余数就是秒数
- 这是处理时间换算的经典模板

### 练习2：运算符优先级

**题目：** 计算和并解释差异。

**答案：**

```python
a = 15
b = 8
c = 23

print(a + b + c)               # 46
print(a * b * c)               # 2760

result1 = (a + b) * c          # (15+8)*23 = 23*23 = 529
result2 = a + b * c            # 15 + (8*23) = 15+184 = 199

print(result1)                 # 529
print(result2)                 # 199
print(result1 == result2)      # False
```

**为什么不同？**
- `(a + b) * c`：括号改变了优先级，先算加法再算乘法
- `a + b * c`：乘法优先级高于加法，先算 `b * c`，再和 `a` 相加
- 就像 `(2+3)×4=20` 而 `2+3×4=14` 一样

### 练习3：奖学金判断

**题目：** 判断是否满足"总分 ≥ 240 且 数学 ≥ 90"。

**答案：**

```python
chinese = 88
math = 95
english = 73

total = chinese + math + english                     # 256
can_get = (total >= 240) and (math >= 90)            # True and True → True

print(f"总分为{total}，数学{math}分，奖学金资格：{can_get}")
# 输出：总分为256，数学95分，奖学金资格：True
```

**解析：**
- 先分别计算两个条件：总分是否达标、数学是否达标
- 用 `and` 连接，两边都满足才返回 `True`
- 小明的总分 256 ≥ 240，数学 95 ≥ 90，两个条件都满足，结果为 `True`


## 3.5 字符串

### 练习1：方法链清洗

**题目：** 一行代码完成：去空格 → 全小写 → 替换。

**答案：**

```python
s = "  Python is Amazing!  "

result = s.strip().lower().replace("amazing", "powerful")
print(result)   # 输出：python is powerful!
```

**解析：**
- 方法链：每个方法返回一个新字符串，后面可以继续调方法
- 执行顺序：`strip()` → `lower()` → `replace()`
- 注意：`replace()` 是区分大小写的，所以先 `lower()` 把 `Amazing` 变成 `amazing`，然后再匹配替换

### 练习2：手机号处理

**题目：** 去掉连字符 + 中间四位遮挡。

**答案：**

```python
phone = input("请输入手机号（格式：138-1234-5678）：")

# 去掉连字符
pure = phone.replace("-", "")
print(f"纯数字：{pure}")

# 中间四位遮挡
parts = phone.split("-")         # ['138', '1234', '5678']
masked = "-".join([parts[0], "****", parts[2]])
print(f"脱敏显示：{masked}")
```

**输出示例：**

```
纯数字：13812345678
脱敏显示：138-****-5678
```

**解析：**
- `replace("-", "")` 把连字符替换为空字符串，实现删除效果
- `split("-")` 按连字符拆成三部分
- `join()` 把前、中（替换为 `****`）、后重新拼起来
- 这是处理格式化数据的常见模式

### 练习3：字符串切片

**题目：** 对 `"Python基础教程"` 进行三种切片输出。

**答案：**

```python
s = "Python基础教程"

print(s[:6])      # 输出：Python（前 6 个字符，位置 0~5）
print(s[6:])      # 输出：基础教程（从位置 6 到末尾）
print(s[::-1])    # 输出：程教础基nohtyP（整个字符串倒序）
```

**解析：**
- `s[:6]`：从 0 开始到索引 6（不包含），取前 6 个字符
- `s[6:]`：从索引 6 开始到末尾
- `s[::-1]`：步长为 -1，从右到左取每一个字符，实现倒序
- 切片的三个参数 `[start:end:step]` 可以灵活组合出各种截取效果
