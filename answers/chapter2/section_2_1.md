### 练习1：输出图形

**题目：** 编写程序，输出以下图形：

```
*
**
***
****
*****
```

**答案：**

```python
print("*")
print("**")
print("***")
print("****")
print("*****")
```

**解析：**
- 每行调用一次 `print()`，自动换行
- 逐步增加 `*` 的数量
- 也可以使用 `print("*" * i)` 结合循环实现（学完循环后就能理解）

### 练习2：自我介绍

**题目：** 定义变量存储名字和年龄，使用 f-string 打印介绍。

**答案：**

```python
name = "小明"
age = 20
print(f"大家好，我叫{name}，今年{age}岁，很高兴学习Python！")
```

**输出：**

```
大家好，我叫小明，今年20岁，很高兴学习Python！
```

**解析：**
- 变量用 `变量名 = 值` 定义
- f-string 中用 `{变量名}` 嵌入变量
- `print()` 将拼接后的字符串输出到屏幕

### 练习3：sep 和 end 参数

**题目：** 使用 `sep` 参数输出日期，使用 `end` 参数连续输出文字。

**答案：**

```python
# 使用 sep 参数输出日期
print("2026", "09", "29", sep="-")

# 使用 end 参数连续输出
print("加载中", end="")
print("...", end="")
print("完成！")
```

**输出：**

```
2026-09-29
加载中...完成！
```

**解析：**
- `sep="-"` 将三个参数用 `-` 连接
- `end=""` 取消默认的换行符，使后续 `print()` 在同一行继续输出
