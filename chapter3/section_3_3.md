## 3.3 基本输入输出

程序的价值在于"与人交互"——接收用户的输入，经过处理后输出结果。Python 提供了极为简洁的输入输出机制：用 `print()` 输出信息，用 `input()` 接收输入。本节将全面讲解这两个核心函数的使用技巧。

### 3.3.1 输出：print() 函数详解

`print()` 是 Python 中最常用的内置函数。在第 2 章中我们已经用它打印了 "Hello, World!"，现在来深入理解它的全部能力。

#### 基本用法回顾

```python
print("Hello, World!")  # 输出一行文本
print(42)               # 输出数字
print(3.14)             # 输出浮点数
print(True)             # 输出布尔值
```

#### 同时输出多个值

`print()` 可以接受多个参数，用逗号分隔，输出时自动用**空格**隔开：

```python
name = "小明"
age = 20
print("姓名：", name, "年龄：", age)
# 输出：姓名： 小明 年龄： 20
```

#### sep 参数：自定义分隔符

默认情况下，多个值之间用空格分隔。通过 `sep` 参数可以自定义分隔符：

```python
print("2026", "09", "29", sep="-")    # 输出：2026-09-29
print("张", "三", sep="")             # 输出：张三（去掉空格）
print("苹果", "香蕉", "橘子", sep="、") # 输出：苹果、香蕉、橘子
```

\begin{tipbox}

**sep 的常见用途**

- `sep="-"`：拼接日期
- `sep=""`：拼接姓和名
- `sep=", "`：生成 CSV 格式
- `sep="\n"`：每个值占一行

\end{tipbox}

#### end 参数：自定义行尾

`print()` 默认在输出末尾自动添加换行符 `\n`，因此每次调用都会换行。通过 `end` 参数可以改变这一行为：

```python
# 默认行为：每次输出后换行
print("第一行")
print("第二行")
# 输出：
# 第一行
# 第二行

# 自定义 end：不换行
print("加载中", end="")
print("...", end="")
print("完成！")
# 输出：加载中...完成！

# end 设为空格
print("苹果", end=" ")
print("香蕉", end=" ")
print("橘子")
# 输出：苹果 香蕉 橘子
```

\begin{definitionbox}

**print() 的完整签名**

```python
print(*objects, sep=' ', end='\n', file=None, flush=False)
```

- `*objects`：要输出的值，可以写多个
- `sep`：值之间的分隔符，默认空格
- `end`：输出末尾的字符，默认换行符
- `file`：输出目标（默认屏幕，也可以写入文件）
- `flush`：是否立即刷新输出缓冲区

\end{definitionbox}

#### 转义字符：输出特殊符号

在字符串中，有些字符无法直接输入（如换行、引号），需要用"转义字符"表示：

| 转义字符 | 含义 | 示例 | 输出结果 |
|:---------|:-----|:-----|:---------|
| `\n` | 换行 | `print("第一行\n第二行")` | 两行文本 |
| `\t` | 制表符（Tab） | `print("姓名\t年龄")` | 姓名&nbsp;&nbsp;&nbsp;&nbsp;年龄 |
| `\\` | 反斜杠本身 | `print("C:\\Users")` | C:\Users |
| `\'` | 单引号 | `print('It\'s ok')` | It's ok |
| `\"` | 双引号 | `print("他说：\"你好\"")` | 他说："你好" |

```python
# 转义字符实战
print("商品\t单价\t数量")          # 用Tab对齐
print("苹果\t5.0\t3")
print("香蕉\t3.5\t5")
# 输出：
# 商品    单价    数量
# 苹果    5.0     3
# 香蕉    3.5     5

print("文件路径：C:\\Users\\Admin\\Desktop")  # 输出反斜杠
# 输出：文件路径：C:\Users\Admin\Desktop
```

### 3.3.2 输入：input() 函数详解

`input()` 用于从键盘接收用户输入。程序执行到 `input()` 时会暂停，等待用户输入并按下回车。

#### 基本用法

```python
name = input("请输入你的名字：")
print("你好，", name)
```

运行效果：

```
请输入你的名字：小明
你好， 小明
```

\begin{warningbox}

**input() 的关键特性：返回值永远是字符串！**

无论用户输入的是数字还是文字，`input()` 返回的都是字符串类型。如果想用输入的值做数学计算，必须先做类型转换。

\end{warningbox}

#### 输入数字：类型转换

```python
# 错误示范：直接计算会报错
age = input("请输入你的年龄：")
# next_year = age + 1  # ❌ TypeError: 字符串和整数不能相加

# 正确做法：先转换类型
age = int(input("请输入你的年龄："))
next_year = age + 1
print(f"明年你{next_year}岁")
```

```python
# 输入小数
height = float(input("请输入你的身高（米）："))
print(f"你的身高是{height}米")
```

#### 一次接收多个输入

```python
# 方法一：多次调用 input()
name = input("姓名：")
age = input("年龄：")
city = input("城市：")
print(f"{name}，{age}岁，来自{city}")

# 方法二：用 split() 分割同一行的多个输入
data = input("请输入姓名和年龄（用空格分隔）：").split()
name = data[0]
age = int(data[1])
print(f"{name}，{age}岁")
```

运行效果：

```
请输入姓名和年龄（用空格分隔）：小明 20
小明，20岁
```

### 3.3.3 格式化输出：让输出更美观

前面的例子中我们多次使用了 `f"{变量}"` 这种写法，这叫 **f-string**（格式化字符串字面量），是 Python 3.6+ 最推荐的字符串格式化方式。

#### f-string：现代 Python 的首选

```python
name = "小明"
age = 20
height = 1.75

# 基本用法：变量直接嵌入 {}
print(f"我叫{name}，今年{age}岁，身高{height}米")

# 花括号内可以写表达式
print(f"明年我{age + 1}岁")            # 输出：明年我21岁
print(f"身高是{height * 100}厘米")      # 输出：身高是175.0厘米

# 结合列表
scores = [88, 95, 79]
print(f"最高分：{max(scores)}，最低分：{min(scores)}")
```

#### 数字格式化

f-string 可以对数字进行格式化，格式为 `{变量:格式说明}`：

| 格式 | 含义 | 示例（值=3.1415926） | 输出 |
|:-----|:-----|:---------------------|:-----|
| `:.2f` | 保留 2 位小数 | `f"{值:.2f}"` | `3.14` |
| `:.0f` | 取整（四舍五入） | `f"{值:.0f}"` | `3` |
| `:.2%` | 百分比格式 | `f"{0.856:.2%}"` | `85.60%` |
| `:,` | 千分位分隔 | `f"{1000000:,}"` | `1,000,000` |
| `:>10` | 右对齐，宽度 10 | `f"{'abc':>10}"` | `&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;abc` |
| `:<10` | 左对齐，宽度 10 | `f"{'abc':<10}"` | `abc&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;` |
| `:^10` | 居中对齐，宽度 10 | `f"{'abc':^10}"` | `&nbsp;&nbsp;&nbsp;abc&nbsp;&nbsp;&nbsp;&nbsp;` |

```python
# 实战：打印整齐的账单
price = 9.9
quantity = 3
total = price * quantity

print(f"单价：¥{price:.2f}")
print(f"数量：{quantity}")
print(f"总价：¥{total:.2f}")
# 输出：
# 单价：¥9.90
# 数量：3
# 总价：¥29.70
```

```python
# 实战：对齐输出表格
print(f"{'商品':<10}{'单价':>8}{'数量':>8}")
print(f"{'苹果':<10}{5.0:>8.1f}{3:>8}")
print(f"{'香蕉':<10}{3.5:>8.1f}{5:>8}")
print(f"{'西瓜':<10}{12.0:>8.1f}{1:>8}")
# 输出：
# 商品            单价      数量
# 苹果             5.0       3
# 香蕉             3.5       5
# 西瓜            12.0       1
```

#### format() 方法和 % 格式化（了解即可）

```python
name = "小明"
age = 20

# .format() 方法（Python 2.6+）
print("我叫{}，今年{}岁".format(name, age))
print("我叫{0}，今年{1}岁，{0}来自北京".format(name, age))

# % 格式化（Python 2 风格，不推荐）
print("我叫%s，今年%d岁" % (name, age))
```

> **建议：** 使用 f-string 即可，它最简洁、最直观、性能最好。

### 3.3.4 综合示例：一个完整的交互程序

将输入和输出结合起来，写一个简单的"用户信息采集"程序：

```python
print("=" * 30)
print("欢迎使用用户信息采集系统")
print("=" * 30)

# 接收用户输入
name = input("请输入姓名：")
age = int(input("请输入年龄："))
height = float(input("请输入身高（米）："))
city = input("请输入所在城市：")
hobby = input("请输入爱好：")

# 计算
birth_year = 2026 - age
bmi = 70 / (height ** 2)  # 假设体重70kg，计算BMI

# 格式化输出
print("\n" + "=" * 30)
print("用户信息汇总")
print("=" * 30)
print(f"姓名：{name}")
print(f"年龄：{age}岁（约{2026 - age}年出生）")
print(f"身高：{height}米")
print(f"城市：{city}")
print(f"爱好：{hobby}")
print(f"BMI指数：{bmi:.1f}")
print("=" * 30)
```

运行效果：

```
==============================
欢迎使用用户信息采集系统
==============================
请输入姓名：小明
请输入年龄：20
请输入身高（米）：1.75
请输入所在城市：北京
请输入爱好：编程

==============================
用户信息汇总
==============================
姓名：小明
年龄：20岁（约2006年出生）
身高：1.75米
城市：北京
爱好：编程
BMI指数：22.9
==============================
```
