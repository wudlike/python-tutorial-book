## 3.4 基本运算符

运算符是代码中进行计算和判断的"符号工具"，就像数学中的"+-×÷"。Python 提供了丰富的运算符，本节聚焦最核心的四大类：算术运算、比较运算、逻辑运算和赋值运算。

### 3.4.1 算术运算符

算术运算符用于完成加、减、乘、除等数学计算，是最基础的一类运算符。

| 运算符 | 含义 | 示例 | 结果 |
|:------:|:-----|:-----|:----:|
| `+` | 加法 | `10 + 3` | `13` |
| `-` | 减法 | `10 - 3` | `7` |
| `*` | 乘法 | `10 * 3` | `30` |
| `/` | 除法（结果总是浮点数） | `10 / 3` | `3.333...` |
| `//` | 整除（向下取整） | `10 // 3` | `3` |
| `%` | 取余（模运算） | `10 % 3` | `1` |
| `**` | 幂运算 | `10 ** 3` | `1000` |

```python
a = 10
b = 3

print(a + b)     # 13
print(a - b)     # 7
print(a * b)     # 30
print(a / b)     # 3.3333333333333335
print(a // b)    # 3（整除，丢弃小数部分）
print(a % b)     # 1（10 ÷ 3 = 3 余 1）
print(a ** b)    # 1000（10 的 3 次方）
```

---

\begin{tipbox}
**整数还是浮点数？**

- `/` 的结果**永远**是浮点数：`4 / 2` 结果是 `2.0`，不是 `2`
- `//` 的结果类型跟随操作数：整数相除得整数，浮点数相除得浮点数（如 `10.0 // 3` → `3.0`）
\end{tipbox}

---

**取余运算（`%`）的实用场景：**

```python
num = 17
print(num % 2)          # 1 → 17 是奇数
print(num % 2 == 0)     # False → 判断奇偶的常用写法

minutes = 150
print(minutes // 60)    # 2 → 小时数
print(minutes % 60)     # 30 → 剩余分钟数（2小时30分）
```

### 3.4.2 比较运算符

比较运算符用来比较两个值的大小关系，返回布尔值（`True` 或 `False`）。它是 `if` 语句、循环条件等逻辑控制的基础。

| 运算符 | 含义 | 示例 | 结果 |
|:------:|:-----|:-----|:----:|
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `5 != 3` | `True` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于等于 | `5 >= 5` | `True` |
| `<=` | 小于等于 | `5 <= 3` | `False` |

```python
score = 85
print(score >= 60)       # True → 及格判断
print(score == 100)      # False → 满分判断
print(score != 0)        # True → 非零判断

name = "Alice"
print(name == "Alice")   # True → 字符串也可以比较（按字典序）
print(len(name) > 3)     # True → 长度大于 3
```

---

\begin{warningbox}
**一个经典陷阱：`=` vs `==`**

- `=` 是**赋值**：把右边的值放进左边的变量
- `==` 是**比较**：判断左右两边是否相等

```python
x = 10     # 正确：把 10 赋给 x
x == 10    # 正确：判断 x 是否等于 10（结果是 True）
x = 10     # 如果本来想写 if x == 10: 却写成了 if x = 10: → 报错！
```

初学者最常见的错误之一就是把 `==` 写成 `=`，养成良好的输入习惯非常重要。
\end{warningbox}

---

### 3.4.3 逻辑运算符

逻辑运算符用于组合多个条件，形成"与、或、非"的判断逻辑。

| 运算符 | 含义 | 示例 | 结果 |
|:------:|:-----|:-----|:----:|
| `and` | 与（两边都为 True 才为 True） | `True and False` | `False` |
| `or` | 或（至少一边为 True 就为 True） | `True or False` | `True` |
| `not` | 非（取反） | `not True` | `False` |

```python
score = 92
age = 20

print(score >= 90 and age <= 22)   # True → 优秀且年轻
print(score < 60 or age > 25)      # False → 都不满足
print(not (score < 60))            # True →"分数不小于 60"的等价写法
```

**短路求值：** Python 执行逻辑运算时会"偷懒"——一旦能确定结果就不再往后算，这可以提高程序效率：

```python
x = 0
print(x != 0 and 10 / x > 2)   # False（因为 x != 0 为 False，不会执行 10/x，避免了除零错误）
print(x == 0 or 10 / x > 2)    # True（因为 x == 0 为 True，不会执行 10/x）
```

---

\begin{definitionbox}
**逻辑运算真值表**

| A | B | A and B | A or B | not A |
|:--:|:--:|:-------:|:------:|:-----:|
| True | True | True | True | False |
| True | False | False | True | False |
| False | True | False | True | True |
| False | False | False | False | True |

这张表涵盖了所有逻辑组合，初学时可以对着看。
\end{definitionbox}

### 3.4.4 赋值运算符

赋值运算符不止 `=`，还有一类"先运算再赋值"的缩写形式，让代码更简洁。

| 运算符 | 等价写法 | 含义 |
|:------:|:---------|:-----|
| `=` | `x = 5` | 直接赋值 |
| `+=` | `x = x + 3` | 加后赋值 |
| `-=` | `x = x - 3` | 减后赋值 |
| `*=` | `x = x * 3` | 乘后赋值 |
| `/=` | `x = x / 3` | 除后赋值 |
| `//=` | `x = x // 3` | 整除后赋值 |
| `%=` | `x = x % 3` | 取余后赋值 |
| `**=` | `x = x ** 3` | 幂后赋值 |

```python
count = 0

count += 1      # count = 1（计数器加1，非常常用）
count += 5      # count = 6
count *= 2      # count = 12
count //= 5     # count = 2（12 // 5 = 2）
```

### 3.4.5 运算符优先级

当多个运算符混合出现时，Python 按照优先级从高到低执行，就像数学中"先乘除后加减"一样。

| 优先级（高→低） | 运算符 | 说明 |
|:---------------:|:-------|:-----|
| 1 | `()` | 括号（最高优先级） |
| 2 | `**` | 幂运算 |
| 3 | `* / // %` | 乘、除、整除、取余 |
| 4 | `+ -` | 加、减 |
| 5 | `> < >= <= == !=` | 比较运算 |
| 6 | `not` | 逻辑非 |
| 7 | `and` | 逻辑与 |
| 8 | `or` | 逻辑或 |
| 9 | `= += -= *= ...` | 赋值运算（最低） |

**不确定优先级时，加括号就好。** 括号不仅让结果正确，也让代码更清晰：

```python
result = 10 + 5 * 2          # 20（先乘后加）
result = (10 + 5) * 2        # 30（括号改变顺序）

score = 85
is_valid = score >= 60 and score <= 100     # True
is_valid = (score >= 60) and (score <= 100)  # 加括号后意图更清晰
```
