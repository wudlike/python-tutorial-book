## 3.2 变量与数据类型

如果把代码比作"处理信息的工厂"，那变量就是工厂里的"容器"——用来存放数字、文字、列表等各种信息；而数据类型则是"容器的标签"，告诉 Python 这个容器里装的是什么类型的信息，该用什么方式处理。本节带你掌握变量的定义与使用，以及 Python 中最常用的 5 种数据类型。

### 3.2.1 变量：给信息起个"好名字"

变量的核心作用是"存储信息并反复使用"。比如你想记录一个学生的姓名和成绩，不用每次都写具体值，而是用变量把值存起来，后续直接调用变量即可。

#### 变量的定义：`名字 = 值`（赋值语句）

语法：用 `=`（赋值符号，不是"等于"）把"值"赋给"变量名"，格式为 `变量名 = 值`。

```python
# 定义变量：存储学生信息
student_name = "张三"  # 变量名 student_name，存储"文字"（姓名）
student_age = 18       # 变量名 student_age，存储"整数"（年龄）
student_score = 95.5   # 变量名 student_score，存储"小数"（成绩）

# 使用变量：直接调用变量名，就能获取里面的值
print(student_name)    # 输出：张三
print(student_age + 2) # 变量可参与计算，输出：20（18+2）
print(f"{student_name}的成绩是{student_score}分") # 输出：张三的成绩是95.5分
```

\begin{definitionbox}

**`=` 不是"等于"，而是"赋值"**

`a = 5` 表示"把 5 这个值放进名叫 `a` 的变量里"，不是"a 等于 5"。变量定义后才能使用，如果没定义就写 `print(score)`，会报错 `NameError: name 'score' is not defined`（变量未定义）。

\end{definitionbox}

#### 变量名的"规矩"：3 个必须遵守 + 2 个推荐

变量名不能随便起，Python 有严格的命名规则，违反会直接报错。

**必须遵守的 3 条规则（硬约束）：**

| 规则 | ✅ 正确 | ❌ 错误 |
|:-----|:--------|:--------|
| 只能包含字母、数字、下划线 | `user_name` `age18` | `user name`（有空格）、`用户年龄`（中文） |
| 不能以数字开头 | `age18` `_total` | `18age` |
| 不能用 Python 关键字 | — | `if = 10` `print = "hello"` |

**推荐遵守的 2 条习惯（软约束，提升可读性）：**

1. **见名知意**：变量名要能反映存储的内容
   - ✅ 推荐：`user_phone`（存储用户手机号）、`product_price`（存储商品价格）
   - ❌ 不推荐：`a` `b` `x1`（光看名字不知道存的是什么）

2. **用"蛇形命名法"**：多个单词用下划线 `_` 连接（Python 官方推荐）
   - ✅ 推荐：`student_score` `order_date`
   - ❌ 不推荐：`studentscore`（单词连在一起，难读）、`StudentScore`（这是 Java 的命名习惯）

#### 变量的修改：重新赋值即可

变量存储的值不是固定的，后续可以用新的赋值语句修改，新值会覆盖旧值：

```python
# 初始值
apple_price = 5.9
print(apple_price)  # 输出：5.9

# 修改值（覆盖旧值）
apple_price = 4.9
print(apple_price)  # 输出：4.9（旧值 5.9 被替换）

# 用变量修改变量（更灵活）
apple_price = apple_price - 1  # 先算右边：4.9-1=3.9，再赋给左边
print(apple_price)  # 输出：3.9
```

### 3.2.2 数据类型：给变量"贴标签"

Python 会自动识别变量存储的值，给它分配对应的"数据类型"——不同类型的处理方式不同（比如数字能计算，文字不能计算）。新手只需先掌握以下 5 种最常用的类型。

#### 怎么看变量的类型？用 `type()` 函数

```python
name = "李四"       # 字符串（文字）
age = 20            # 整数（没有小数点的数字）
height = 1.75       # 浮点数（有小数点的数字）
is_student = True   # 布尔值（对/错）
hobbies = ["篮球", "游戏"]  # 列表（装多个值）

# 查看类型
print(type(name))       # 输出：<class 'str'>
print(type(age))        # 输出：<class 'int'>
print(type(height))     # 输出：<class 'float'>
print(type(is_student)) # 输出：<class 'bool'>
print(type(hobbies))    # 输出：<class 'list'>
```

#### 5 种常用数据类型详解

**（1）字符串（str）：存储文字信息**

定义：用英文单引号 `''` 或双引号 `""` 包裹的内容（单双引号无区别，选一种保持一致即可）。

```python
nickname = '小明'
address = "北京市朝阳区"

# 特殊用法：引号嵌套（单引号里套双引号，或反之）
intro = '他说："Python很简单！"'  # 正确：单引号套双引号
intro2 = "I'm a student"         # 正确：双引号套单引号

# 常用操作：拼接字符串（用 + 连接）
full_name = "张" + "三"  # 拼接后为 "张三"
```

> **注意：** 字符串不能和数字直接计算，比如 `print("年龄：" + 20)` 会报错，需要先把数字转成字符串（详见 3.2.3 节类型转换）。

**（2）整数（int）：存储没有小数点的数字**

定义：直接写数字，不用加引号，如 `10` `0` `-5`。常用场景：年龄、数量、序号等。

```python
count = 100      # 正数
temperature = -5 # 负数
zero = 0         # 零

# 常用操作：加减乘除、取整等计算
total = count + 50  # 加法：150
remainder = 10 % 3  # 取余：1（10除以3余1）
square = 4 ** 2     # 平方：16（4的2次方）
```

**（3）浮点数（float）：存储有小数点的数字**

定义：写数字时带小数点，如 `3.14` `0.5` `-2.8`。常用场景：身高、体重、价格、分数等。

```python
weight = 62.5    # 体重62.5公斤
price = 9.9      # 价格9.9元

total_price = price * 2  # 9.9*2=19.8
```

\begin{tipbox}

**浮点数的微小误差**

浮点数计算可能有微小误差（如 `0.1 + 0.2` 结果是 `0.30000000000000004`），这是计算机存储浮点数的特性。后续处理金额时可通过专用库解决（如 `decimal` 库），新手暂时不用纠结。

\end{tipbox}

**（4）布尔值（bool）：存储"对"或"错"**

定义：只有两个值——`True`（对，真）和 `False`（错，假），首字母必须大写（小写 `true` 会被当成变量）。

```python
is_pass = True    # 及格了（对）
has_money = False # 没带钱（错）

# 常用操作：结合判断语句
score = 85
is_excellent = score >= 90  # 判断85是否>=90，结果为 False
print(is_excellent)         # 输出：False
```

**（5）列表（list）：存储多个值的"容器"**

定义：用方括号 `[]` 包裹多个值，值之间用逗号 `,` 分隔，值的类型可以不同。

```python
# 存储多个成绩（同类型）
score_list = [85, 92, 78, 95]
# 存储个人信息（不同类型）
person_info = ["王五", 22, 1.80, True]

# 取列表中的值（用"索引"，从0开始数）
print(score_list[0])    # 取第1个值（索引0），输出：85
print(person_info[2])   # 取第3个值（索引2），输出：1.80

# 添加值到列表
score_list.append(88)
print(score_list)       # 输出：[85, 92, 78, 95, 88]
```

\begin{definitionbox}

**列表索引从 0 开始，不是 1！**

这是初学者最容易踩的坑：

- `列表[0]` → 第 1 个值
- `列表[1]` → 第 2 个值
- `列表[3]` → 第 4 个值

以此类推。记住：**索引 = 第几个 - 1**。

\end{definitionbox}

### 3.2.3 数据类型转换：让不同类型"配合工作"

有时候不同类型的变量需要一起用（比如"文字 + 数字"拼接），这时候需要手动转换类型。Python 提供了 4 个常用的转换函数：

| 函数 | 作用 | 示例 |
|:-----|:-----|:-----|
| `str()` | 转为字符串 | `str(20)` → `"20"` |
| `int()` | 转为整数 | `int("123")` → `123` |
| `float()` | 转为浮点数 | `float("3.14")` → `3.14` |
| `bool()` | 转为布尔值 | `bool(0)` → `False` |

#### 场景 1：字符串和数字拼接

```python
age = 20
# print("我的年龄是" + age)  # ❌ 字符串和整数不能直接拼接
print("我的年龄是" + str(age))  # ✅ 先转字符串
```

#### 场景 2：用户输入转数字

`input()` 函数获取用户输入时，不管输入的是什么，结果都是**字符串**，想做计算必须转成数字：

```python
age_input = input("请输入你的年龄：")
print(type(age_input))  # 输出：<class 'str'>（即使输入20，也是字符串）

age = int(age_input)    # 转成整数
next_year_age = age + 1
print(f"明年你{next_year_age}岁")  # 输入20，输出：明年你21岁
```

#### 场景 3：浮点数转整数

```python
height = 1.75
height_int = int(height)
print(height_int)  # 输出：1（直接截断小数，不是四舍五入）
```

#### 转换的"小陷阱"

转换必须符合逻辑，不能把"文字"转成数字：

```python
# ✅ 正确：数字字符串转整数
num = int("123")   # num = 123

# ❌ 错误：非数字字符串转整数
num = int("一百二十三")  # 报错 ValueError
```

### 3.2.4 小结

| 要点 | 核心内容 |
|:-----|:---------|
| **变量** | 用 `变量名 = 值` 定义，遵守"见名知意、蛇形命名"原则，可重新赋值 |
| **str（字符串）** | `"文字"`，存文本 |
| **int（整数）** | `10`，存无小数点的数 |
| **float（浮点数）** | `3.14`，存带小数点的数 |
| **bool（布尔值）** | `True` / `False`，存对/错 |
| **list（列表）** | `[1, "a"]`，存多个值，索引从 0 开始 |
| **类型转换** | `str()` / `int()` / `float()` 实现不同类型间的转换 |
